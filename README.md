# Python Password Manager

This is a simple command-line password manager I built using Python as part of improving my programming and problem-solving skills through hands-on practice.

I wanted to work on a project that was practical and could help me better understand concepts such as file handling, application workflows, and basic security in Python. The project allows users to store, search, and manage credentials in a simple and organized way.

While building it, I also explored basic encryption concepts to better understand how sensitive information such as passwords can be handled more securely in applications.

## Features

* Add and save passwords
* Search saved credentials
* Delete stored passwords
* Generate strong passwords
* Store data using JSON
* Basic password encryption using Fernet

## Technologies Used

* Python
* Cryptography Library
* JSON File Handling

## Project Structure

```text
python-password-manager/
│
├── main.py

```

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
